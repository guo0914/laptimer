请用 iPhone 自带的 Safari 打开本页，其它浏览器不支持直接安装。

版本 1.0 iOS 17.0 及以上

安装步骤

  1. 用 Safari 打开本页，点上面的「安装到 iPhone」，弹窗选「安装」。
  2. 回到桌面，等图标出现（图标可能是灰的，属正常）。
  3. 首次打开会提示「未受信任的开发者」。去 设置 → 通用 → VPN 与设备管理，点你的 Apple ID，选「信任」。
  4. 回桌面点开 App 即可使用。

签名有效期 7 天

免费 Apple ID 签名的 App 只能用 7 天，到期后图标打不开。到期时重新签名、再回到本页装一次即可，计时记录不会丢（存在 App 自己的沙盒里，覆盖安装会保留）。

换台设备装

把本页链接发到那台设备，用 Safari 打开即可。
